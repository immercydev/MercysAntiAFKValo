## ✨ About

Tired of being marked AFK when you step away from your PC?

**Mercy's Anti AFK Valo** is a Windows desktop utility featuring a custom glass-themed interface and configurable keyboard and mouse automation.

Designed with simplicity, customization and a clean gaming aesthetic in mind.

## ⚡ Features

- 🎨 Custom glass-themed interface
- 🎮 Start / Stop controls
- ⌨️ Configurable global hotkey (F8 by default)
- 🎯 Customizable action toggles
- ⚙️ Adjustable action timing
- 🖱️ Keyboard and mouse input automation
- 📊 Live action status
- 💜 Custom application branding

## 🛠️ Run from Source

Requirements:
- Windows
- Python 3.x
- pip

Clone the repository:

```bash
git clone https://github.com/immercydev/MercysAntiAFKValo.git
cd MercysAntiAFKValo
```

Install dependencies:

```bash
pip install keyboard
```

Run:

```bash
python mercys_anti_afk_valo.py
```

## 🔨 Build Your Own EXE

Run:

```bash
build_exe.bat
```

The generated executable will be inside the `dist` folder.
